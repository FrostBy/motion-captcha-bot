# motion-captcha-bot

Антиспам-бот для Telegram, встречающий новичков анимированной математической капчей, читаемой только в движении. Одиночный кадр, как и попиксельное усреднение всех кадров, статистически ровный шум: OCR, скриншоты и мультимодальные модели не видят ничего, а человек считывает цифры мгновенно за счёт восприятия движения.

English version: [README.md](README.md)

## Как это работает

Выражение `N+M` рисуется двумя слоями шума, движущимися друг относительно друга. Область цифр и фон имеют одинаковую статистику текстуры, поэтому цифры существуют только как согласованное движение, а не как пиксели:

- Стоп-кадр: ровный шум, OCR нечего читать.
- Усреднение кадров (pixel delay map): снова ровный шум.
- Глаз человека: читает цифры за доли секунды.

Поверх базовой механики есть опциональные щиты от автоматического анализа видео:

| Щит | Что делает | Что ломает |
|---|---|---|
| Движение, пресет 2 | Оба слоя едут в одну сторону с разными плавающими по синусоиде скоростями | Shift-matching: вычитание карт совпадений `+сдвиг` и `-сдвиг` даёт ноль, а постоянного межкадрового смещения не существует |
| Спринкл | Каждый кадр пересыпает долю пикселей свежим шумом | Загрязняет карты оптического потока и совпадений; глаз усредняет мерцание |
| Приманка | Вшивает в поле еле заметное статичное фейковое выражение | Усреднение кадров проявляет фейк вместо ответа, а ответ суммой фейка запускает временную блокировку |

## Правила модерации

- Новичок должен прислать верное число за отведённое время (по умолчанию 60 с); за провал следует временная блокировка (по умолчанию 5 мин), после которой можно вернуться и попробовать снова.
- Все сообщения ожидающего новичка, кроме верного ответа, удаляются.
- Кого бот уже видел в чате и кто уже проходил капчу, её не получает.
- Боты из списка разрешённых и боты, добавленные администратором, остаются; остальные кикаются.
- Если капча не отрендерилась, новичок пропускается с громкой строкой в логе, никто не застревает из-за инфраструктурной проблемы.

Состояние хранится как JSON-снимок на диске: живёт в памяти, атомарно сбрасывается раз в несколько секунд и при остановке. Рестарты ничего важного не теряют.

## Быстрый старт

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Добавь бота в группу администратором с правами «удалять сообщения» и «блокировать участников».
3. Создай `.env` рядом с `docker-compose.yml`:

   ```env
   BOT_TOKEN=123456:ABC...
   ```

4. Запусти:

   ```sh
   docker compose up -d --build
   ```

## Настройка

Всё управляется переменными окружения. Без базы данных и админки.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | обязательна | Токен Telegram-бота |
| `CAPTCHA_TIMEOUT_SEC` | `60` | Секунды на ответ новичка |
| `CAPTCHA_STYLE` | `l` | Вид шума: `l` это ленты 2px, `g` это ленты 1px, `dots` это разреженные субпиксельные точки |
| `CAPTCHA_MOTION` | `1` | `1` двигает слои противоходом, `2` двигает их в одну сторону с плавающими скоростями (анти shift-matching) |
| `CAPTCHA_SPRINKLE` | `0` | Доля пикселей, пересыпаемых свежим шумом каждый кадр, `0..1` (например `0.01`); повышает цену анализа, стоит читаемости и веса |
| `CAPTCHA_DECOY` | `false` | Вшить бледное фейковое выражение; ответ по нему запускает временную блокировку |
| `CAPTCHA_MAX_ATTEMPTS` | `3` | Сколько неверных числовых ответов допустимо до блокировки (болтовня просто удаляется и не считается) |
| `CAPTCHA_BAN_SEC` | `300` | Сколько секунд новичок остаётся заблокирован после провала капчи (`60..31536000`) |
| `ALLOWED_BOT_IDS` | не задано | Числовые ID ботов через запятую, разрешённых независимо от добавившего их пользователя; остальных ботов должен добавить администратор |
| `ALLOWED_CHAT_IDS` | не задано | Числовые ID обслуживаемых чатов через запятую; пустое или незаданное значение разрешает все чаты |
| `DATA_FILE` | `data/state.json` | Путь к снимку состояния |
| `MESSAGES_FILE` | `data/messages.json` | Необязательные шаблоны сообщений, см. ниже |
| `FFMPEG_PATH` | `ffmpeg` | Бинарь ffmpeg (в Docker-образе уже есть) |
| `TELEGRAM_TEST_MODE` | `false` | Работать с тестовым окружением Telegram |
| `TELEGRAM_API_ROOT` | Telegram | Корень Bot API для совместимых серверов, например Telegym |
| `CAPTCHA_TEST_SEED` | не задано | Детерминированный seed PRNG для интеграционных тестов; требует `TELEGRAM_API_ROOT` |

## Свои сообщения

Положи `messages.json` в каталог данных, чтобы переопределить тексты бота (на любом языке). Плейсхолдеры: `%username%` превращается в кликабельное упоминание новичка, `%timer%` в отведённые секунды. Шаблоны в формате Telegram HTML.

```json
{
  "captcha": "%username%, докажи, что живой: пришли ответ числом за %timer% секунд, иначе до свидания.",
  "welcome": "%username%, свой человек, добро пожаловать."
}
```

## Разработка

```sh
npm install
npm test          # юнит-тесты, ffmpeg не нужен
npm run typecheck
BOT_TOKEN=... npm run dev
```

Локальная генерация анимации требует ffmpeg в `PATH` (или `FFMPEG_PATH`).
